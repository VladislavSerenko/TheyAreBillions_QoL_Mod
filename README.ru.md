# TAB QoL — They Are Billions

[English](README.md)

Неофициальный мод для Windows: сохранение и загрузка внутри миссий, сброс
технологий кампании, необязательный пропуск геройских миссий со всеми наградами
и скорости от 0,5× до 5×. Есть хоткеи построек и отладочная чит-панель на F12.
Мод устанавливается в вашу локальную копию игры.

## Совместимость

Версия 0.3.1 поддерживает **Steam и GOG x64** для указанных ниже сборок.
Проверенные функции и ограничения описаны в [VALIDATION.md](VALIDATION.md).
Установщик определяет издание по SHA-256 исходного `TheyAreBillions.exe`:

```text
GOG 1.1.4.10:
f502e38dd6840a5d52331c1c8d68ab94c79f620e2dd5453e9bf5168d909433d3
Steam (версия файла EXE 1.0.14.29):
695cef4ad913f9ffd1f9f0508d26862546b130922db53dce716051fe9b0a9d2d
```

Другие сборки, x86 и уже изменённые EXE установщик отклоняет. Совпадения
номера версии недостаточно. Обновление Steam может потребовать обновления мода.
Нужны Windows и .NET Framework 4.6.2 или новее;
сама игра должна нормально запускаться со своими зависимостями.

## Установка

1. Закройте игру и распакуйте `TABQoL-0.3.1.zip` в отдельную папку.
2. Откройте PowerShell в этой папке и выполните:

   ```powershell
   .\TABQoL.Installer.exe inspect 'C:\Games\Steam\steamapps\common\They Are Billions'
   .\Install.ps1 -GameDirectory 'C:\Games\Steam\steamapps\common\They Are Billions'
   ```

   Для GOG укажите его папку, например `C:\Games\They Are Billions`.
   Можно запустить напрямую: `TABQoL.Installer.exe install "папка игры"`.
   Права администратора нужны только при ограничении записи в папку игры.
3. Запустите игру обычным способом (Steam-версию через Steam).
   Настройки: **Options > TAB QoL**, меню: **F11**.

Перед установкой создаются резервные копии исходного EXE и сохранений.
**В Steam исходный EXE остаётся неизменным:** запись CLR AppDomainManager в
`TheyAreBillions.exe.config` загружает мод, а Harmony устанавливает обработчики
в памяти. Существующие параметры запуска и CLR сохраняются. **В GOG установщик
патчит поддерживаемый EXE через dnlib.** Подробности: [INSTALLATION.md](INSTALLATION.md).

Сохраните папку `TABQoL.Installation` внутри игры: она нужна для удаления мода.
Перед обновлением мода, обновлением или проверкой файлов игры в Steam сначала
удалите установленный мод. Установщик отклоняет конфигурацию с чужим
AppDomainManager и не перезаписывает DLL, которые ему не принадлежат.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Быстрое сохранение | F5 |
| Быстрая загрузка | F9 |
| Замедление | `[` |
| Ускорение | `]` |
| Меню мода | F11 |
| Отладочная чит-панель | F12 |

В **Options > TAB QoL** выбираются **0,5×, 1×, 2×, 3×, 4× и 5×** и назначаются
клавиши. Нажмите кнопку с клавишей, затем новую клавишу; Escape отменяет ввод.
Комбинации не поддерживаются. Клавиши должны различаться; Enter, Escape,
Windows и модификаторы зарезервированы. Избегайте конфликтов со штатным
управлением игры. Скобки соответствуют физическим OEM-клавишам Windows;
символы на них зависят от раскладки. Настройки применяются сразу и сохраняются.
Старое назначение F10 по умолчанию переносится на F11, чтобы не открывать
штатное окно снимка карты. Собственные назначения сохраняются. Общие клавиши
мода перехватываются до штатных действий, включая отладочное действие на F11.

Окна мода стали компактнее: содержимое расположено по центру, элементы
выровнены, латунные кнопки действий уменьшены. **OK** возвращает на предыдущий
экран мода. Переключение страниц Save/Load остаётся внутри этого экрана.

### Сохранение и загрузка

F5/F9 работают с быстрым слотом. **F11 > Save / Load** открывает быстрый и **десять
ручных слотов** на двух страницах. Вкладка **Autosaves** содержит пять отдельных
циклических автосохранений. Кнопки Save и Load сгруппированы рядом со строкой.
Слоты разделены по изданию, игре и миссии кампании. После перезапуска
сначала продолжите нужную миссию через обычное меню игры, затем загрузите слот
мода. Снимок восстанавливает состояние колонии и кампании, включая ресурсы,
юнитов и очки кампании. На время записи симуляция приостанавливается.

Сохранение и загрузка доступны в загруженной, продолжающейся миссии, в том
числе на паузе. Во время загрузки и переходов нужно дождаться готовности игры;
для горячих клавиш закройте диалоговые окна. Пока завершённая миссия ещё
загружена, загрузка слотов доступна через F11, в том числе на экране результатов.
На глобальной карте слоты недоступны. Штатные сохранения хранятся отдельно. Каждый
слот сохраняет текущую и предыдущую версии; перед загрузкой проверяются SHA-256.
Слоты старых прохождений остаются на диске до ручного удаления.

По умолчанию автосохранение происходит **каждые 10 минут активной игры**.
В **Options > TAB QoL** можно выбрать **Off** или **5, 10, 15, …, 60 минут**.
Нестандартный интервал из старой версии остаётся видимым и не меняется,
пока вы не выберете один из предложенных вариантов.
Пауза, диалоговые окна и загрузка не учитываются; ускорение игры не меняет
интервал. Пять слотов хранят последние пять автосохранений — около 50 минут
при стандартном интервале. Затем заменяется самый старый слот. Быстрые и ручные
сохранения независимы. После загрузки миссии или изменения интервала таймер
начинается заново; после долгой приостановки пропущенные записи не догоняются.

### Хоткеи построек

Выберите свою постройку. Верхний ряд команд использует **Q W E R T**,
средний — **A S D F G**, нижний — **Z X C V B**. Клавиши соответствуют
фактическому положению иконок, включая категории командного центра.
Это работает для отдельных зданий, найма в казармах и других команд построек.
Разблокировки кампании могут менять положение иконок в сетке.
Подсказки соответствуют текущей сетке команд.
Действуют штатные требования технологий, ресурсов, очереди и размещения.
Escape сохраняет штатные действия «Назад» и отмены строительства.
При выборе юнитов сохраняются их штатные команды.

Если выбрано несколько производственных зданий, хоткей найма добавляет по
одному юниту в очередь каждого подходящего здания. Для каждого действуют
штатные ограничения ресурсов, технологий и очереди: ресурсов может хватить
только на часть выбранных зданий.

Настройки: **F11 > Building hotkeys** или
**Options > TAB QoL > Building hotkeys**. Каждому зданию можно назначить A–Z;
Backspace снимает назначение, Escape отменяет ввод. Внутри категории клавиши
должны различаться, между категориями могут повторяться. Конфликты с общими
клавишами мода запрещены. Комбинации с Shift/Ctrl/Alt/Windows не запускают
строительство. Назначения сохраняются между запусками.
Здания без отдельного назначения показывают **Auto** и используют клавишу
своей видимой ячейки. Пользовательские назначения сохраняются. Если видимая
команда с пользовательской клавишей совпадает с автоматической клавишей
другой команды, автоматическая отключается, чтобы не запускать неверное действие.

### Отладочные читы

**F12** открывает и закрывает панель во время миссии. Доступны бессмертие своих
юнитов, включая героя, защита своих построек, лечение живых юнитов и заполнение
складов золота, дерева, камня, железа и нефти до штатного предела. Защита
распространяется только на игрока; противники продолжают получать урон.
Оба переключателя защиты выключены по умолчанию и сбрасываются при загрузке
или смене миссии. Они не записываются в настройки и снимки сохранений.

**Fill resources** заполняет склады. **Win mission...** запрашивает подтверждение
внутри игры, создаёт
отдельный снимок `before-cheat-win` и запускает штатное завершение миссии.
Закончите обычный экран результатов, чтобы применить прогресс и награды
кампании. Этот чит не собирает пропущенные предметы героя; максимальные
награды по-прежнему выдаёт опция пропуска геройских миссий на глобальной карте.
Изменения ресурсов, здоровья и результаты победы могут попасть в штатные
сохранения. Снимок мода позволяет откатить их, пока загружена нужная миссия.
Для отката до выхода с экрана результатов откройте **F11 > Save / Load** и
загрузите строку `before-cheat-win`. Запись завершённой миссии недоступна.

### Сброс технологий

На глобальной карте нажмите **шестерёнку QoL** рядом с верхними вкладками,
выберите **Reset technologies** и подтвердите **Reset**. Компактное окно
использует родную латунную рамку, галочку и металлические кнопки игры.
Все купленные технологии снимаются с возвратом полной стоимости через штатную
логику игры. Начальные бесплатные технологии остаются. Имперские очки от
снятых технологий также вычитаются: повторная покупка начислит их заново.
Пройденные миссии и их награды сохраняются. Сброс недоступен внутри миссий и
во время перепрохождения. Перед изменением создаётся резервная копия кампании.

### Пропуск геройских миссий

На глобальной карте откройте **шестерёнку QoL** и включите
**Skip hero missions (all rewards)**. Когда вы
подтвердите **Start** для доступной непройденной геройской миссии, она сразу
завершится через штатный обработчик кампании. Начисляются фиксированная награда,
все исследовательские и имперские очки за предметы и обычные разблокировки за
прохождение. Используется выбранная сложность кампании. Уже пройденные миссии
и перепрохождения не дают повторных наград. Колонии и миссии с роем запускаются
обычно. По умолчанию галочка выключена; её положение сохраняется.

## Данные и восстановление

В вашей папке «Документы»:

```text
My Games\They Are Billions\TABQoL\
  Settings.xml       Настройки и клавиши; .bak — предыдущая версия
  Snapshots\         Слоты, разделённые по игре и миссии
  Backups\           Копии перед установкой, Reset и пропуском миссий
  TABQoL.log         Сообщения и ошибки мода
```

Время в названиях копий указано в UTC. Копии установки содержат файлы профиля
и подпапку `Saves`; копии перед изменением кампании — пары файлов сохранения
непосредственно в папке копии. Для восстановления закройте игру, отдельно
скопируйте текущие сохранения и верните нужные `.zxsav`/`.zxcheck`, а при наличии
также `.zxcampaign`/`.zxcheck`, в штатную папку `Saves`, сохраняя точные имена.
Переименовывать штатные сохранения нельзя: сериализация зависит от имени файла.

При ошибке установки прочитайте сообщение и проверьте оставшуюся папку
`TABQoL.Installation`, прежде чем повторять установку. Не перезаписывайте
старой копией файлы, которые магазин или другой мод уже успел изменить.

## Удаление

Закройте игру и выполните:

```powershell
.\Uninstall.ps1 -GameDirectory 'C:\Games\They Are Billions'
# Или: .\TABQoL.Installer.exe uninstall 'C:\Games\They Are Billions'
```

Перед изменениями установщик проверяет контрольные суммы своих файлов и копий.
В Steam он возвращает точный исходный конфиг либо удаляет созданный конфиг,
если раньше его не было, и удаляет принадлежащие моду DLL runtime и Harmony;
EXE остаётся неизменным. В GOG возвращается точный исходный EXE и удаляется
DLL мода. Запись установки архивируется; сохранения, настройки и резервные
копии остаются. Изменённые после установки файлы отмечаются в сообщении
и остаются на месте. Для загрузки слотов мода нужен мод; обычные сохранения
остаются штатными.

## Сборка и публикация

На Windows с .NET SDK 8 или новее:

```powershell
.\Build.ps1 -Package
# Дополнительно проверить установку на вашем исходном совместимом EXE:
.\Build.ps1 -Package -OriginalExe 'C:\путь\к\исходному\TheyAreBillions.exe'
```

Архив появится в `artifacts`. Сборка получает dnlib 4.5.0, Lib.Harmony 2.4.1 и
reference assemblies из NuGet; файлы игры для компиляции не требуются.
Чистая сборка **0.3.1** проходит **80 проверок с обоими поддерживаемыми
исходными EXE**; 57 проверок не требуют файлов игры. Проверки в самой игре
описаны в [VALIDATION.md](VALIDATION.md). Проверяются настройки,
таймер автосохранений, сетка команд, разделение и хранение слотов, повреждение
данных, незавершённая запись и сохранность параметров конфига. `-OriginalExe`
дополнительно проверяет обработчики и метаданные патча GOG, а также установку,
inspect, удаление Steam, проверку принадлежности файлов и точное восстановление
конфига во временных папках. Перезапись EXE Steam запрещена. Параметр принимает
массив путей для одновременной проверки Steam и GOG.
Подробности проверки в игре и ограничения описаны в [VALIDATION.md](VALIDATION.md).
Скорость 5× может ограничиваться производительностью компьютера. Совместимость
с другими модами не проверена. Интерфейс мода в этой версии — английский.

Steam и GOG используют один репозиторий; готовый архив можно прикрепить к
Release. В Git игнорируются `bin`, `obj`, `artifacts`, сохранения
и EXE игры. Не добавляйте установку игры, резервные копии, логи и личные данные.
В проект включён GitHub Actions для сборки и тестов без файлов игры.
